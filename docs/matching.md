# Подбор анкет и мэтчи

## Основной сценарий
Пользователь видит рекомендованные анкеты, может:
- лайкнуть;
- добавить комментарий к лайку;
- пропустить;
- заблокировать;
- пожаловаться.

## Логика рекомендаций
RecommendationService строит список кандидатов и сортирует их по совпадению:
- района;
- места учёбы/работы;
- интересов;
- возраста.

## Основные ограничения
- Исключаются уже лайкнутые анкеты.
- Исключаются пропущенные анкеты.
- Исключаются анкеты из блокировок.
- Учитывается видимость профиля и активный статус пользователя.

## Взаимные симпатии
- MatchService создаёт запись в таблице likes и проверяет наличие взаимного лайка.
- При взаимности создаётся match и отправляется уведомление пользователям.

## Потенциальные проблемы
- Логика сортировки и фильтрации находится в одном сервисе и может быстро разрастаться.
- Для масштабирования потребуется отдельная логика ранжирования и кэширования.
- В текущей реализации нет явного разделения на discovery- и match-потоки.
